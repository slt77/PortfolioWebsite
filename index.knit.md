## SECR Package
Spatially Explicit Capture Recapture

::: {.callout-note}
To access the function, first install SECR, install.packages("secr")
:::

Functions to estimate the density and size of a spatially distributed animal population sampled with an array of passive acoustic monitors (PAMs). Models incorporate distance-dependent detection to maximise the likelihood. Tools are included for data manipulation and model selection.
Spatially explicit capture-recapture is a set of methods for studying marked animals distributed in space. Data consists from the location of detectors and their histories of marked animals. Models for population density and detection are defined in secr. Density models may include spatial/temporal trends, with predictors corresponding to time or behaviour.
